# Privacy

doitfirst has no account, no server and no telemetry. It makes no network requests.

## What is stored

- **Tasks and settings**: kept in `chrome.storage.sync`, so Chrome syncs them between your own devices if you have sync turned on.
- **Session time**: the time left on each site is kept in `chrome.storage.local` and never leaves the device.

Nothing else is read or stored. The extension does not record what you watch, read or search for.

## Permissions

- **storage**: to keep the items above.
- **Access to X, YouTube, Instagram and TikTok**: to show the task list and hide page sections on those sites. It runs nowhere else.

## Changes

If a future version sends anything off the device, such as video titles to a model you chose, this file will say exactly what is sent and to whom before that version is released.
